Design Section 2: Typography System

Fixing the tiny text problem — minimum 13px body, clear hierarchy

Font Stack

UI / Body

Inter

Clean, geometric, great at small sizes. Free on Google Fonts. Fallback: system-ui, sans-serif.

Code / Mono

JetBrains Mono

For code blocks, IDs, API keys, log output. Fallback: ui-monospace, monospace.

Type Scale

Based on 1.25 ratio. No text below 12px anywhere in the system.

display Page Title 30px / 700
h1 Section Heading 24px / 600
h2 Card Heading 20px / 600
h3 Sub Heading 16px / 600
body Body text for paragraphs, descriptions, and general content across all pages. 14px / 400
body-sm Smaller body for table cells, form labels, secondary info. 13px / 400
caption SECTION LABEL 12px / 500 / caps
code api_key_12345 13px / mono
