Layout Rules

Sidebar (≥768px)

240px fixed width. Collapsible to 64px (icons only) via toggle. Grouped nav with section labels. User profile at bottom.

Top Bar

Breadcrumbs, global search (⌘K), theme toggle. Sticky on scroll. Desktop app: Tauri drag region for window controls.

Page Header

Title + subtitle + primary action button. Consistent on every page. Optional tabs for sub-navigation.

Mobile (<768px)

Sidebar hidden. Bottom nav with 4-5 key destinations (Home, Groups, Skills, Settings). Top bar simplified: logo + title + search icon.

Shared Between Apps

Desktop & Dashboard share the same Sidebar, TopBar, PageHeader, BottomNav components. Only difference: Desktop has Tauri window controls + system tray. Dashboard has login page.
